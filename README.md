# Ghosting Counter

Мобильный трекер обещаний: добавляйте друзей или себя, фиксируйте срывы и
смотрите, как меняется индекс доверия.

## Возможности

- Главный экран с общим индексом доверия и забавным статусом.
- Карточки людей с обещанием, количеством срывов и кнопками «сдержал» /
  «сорвал».
- Экран аналитики с недельным графиком на `fl_chart` и рейтингом доверия.
- Создание, редактирование и удаление карточек, включая личную карточку «Это я».
- Редактирование имени профиля.
- Адаптивная навигация: нижняя панель на телефоне и боковая на широком экране.
- Локальное сохранение данных на устройстве.

## Структура кода

- `lib/models/` — модель карточки человека и её сериализация.
- `lib/data/` — интерфейс хранилища и текущая реализация через
  `shared_preferences`.
- `lib/state/` — состояние приложения и операции с обещаниями.
- `lib/presentation/` — экранные компоненты, графики и диалоги.
- `lib/app.dart` — сборка приложения, тема и адаптивная навигация.
- `lib/main.dart` — точка входа.

Хранилище изолировано интерфейсом `PeopleRepository`: его можно заменить на
Firestore, когда Firebase SDK и конфигурация платформ будут добавлены в проект.
Сейчас этот проект **не обращается к Firebase**: в `pubspec.yaml` нет
`firebase_core` / `cloud_firestore`, а конфигурационных файлов Firebase нет.

Firebase — облачная платформа Google: например, Firestore хранит данные на
сервере и синхронизирует их между устройствами, а Firebase Authentication
позволяет пользователям входить в приложение. Одного проекта в Firebase Console
недостаточно: приложениям ещё нужны SDK, конфигурация каждой платформы и правила
доступа к данным. Поэтому пока карточки сохраняются локально и не
синхронизируются с другими устройствами.

## Запуск

```sh
flutter pub get
flutter run
```

Демо-карточки показывают основные состояния интерфейса при первом запуске.
