# Ghosting Counter

Мобильный трекер обещаний: добавляйте друзей или себя, фиксируйте срывы и
смотрите, как меняется индекс доверия.

## Возможности

- Главный экран с общим индексом доверия и забавным статусом.
- Карточки людей с обещанием, количеством срывов и кнопками «сдержал» /
  «сорвал».
- Экран аналитики с недельным графиком на `fl_chart` и рейтингом доверия.
- Создание, редактирование и удаление карточек, включая личную карточку «Это я».
- Редактирование имени профиля.
- Адаптивная навигация: нижняя панель на телефоне и боковая на широком экране.
- Сохранение карточек и профиля в базе SQLite.
- Восемь юмористических уровней доверия и расчёт, сколько обещаний нужно
  сдержать до каждого следующего уровня.
- Регистрация и вход по email/паролю через Firebase Authentication; есть сброс
  пароля и выход из аккаунта. При регистрации задаётся имя, которое можно
  изменить позже в профиле.

## Структура кода

- `lib/models/` — модель карточки человека и её сериализация.
- `lib/data/` — интерфейс хранилища и текущая реализация через
  SQLite.
- `lib/models/trust_level.dart` — уровни доверия и формула прогресса.
- `lib/state/` — состояние приложения и операции с обещаниями.
- `lib/presentation/` — экранные компоненты, графики и диалоги.
- `lib/app.dart` — сборка приложения, тема и адаптивная навигация.
- `lib/main.dart` — точка входа.

Хранилище изолировано интерфейсом `PeopleRepository`. На Android, iOS и
macOS используется SQLite-файл приложения; на Windows и Linux — SQLite через
FFI; в браузере SQLite хранится в IndexedDB. Карточки и имя профиля разделены
по Firebase UID в общей локальной базе. Это локальные данные устройства, они
не синхронизируются с облаком и не переносятся на другое устройство.

Аутентификация использует Firebase Authentication. В Firebase Console включите
**Authentication → Get started**, затем откройте
**Sign-in method → Email/Password → Enable**. Пока этот provider не включён,
Firebase отвечает `configuration-not-found` или `operation-not-allowed`.
Регистрация принимает новый корректный email и пароль от 6 символов; вход
возможен только с данными уже созданного аккаунта. После клонирования проекта
сгенерируйте локальные параметры Firebase командой `flutterfire configure`;
`lib/firebase_options.dart` и платформенные Firebase-конфигурации намеренно
исключены из Git. `firebase.json` и `.firebaserc` оставлены в Git, чтобы можно
было собирать и публиковать Hosting. Пароль приложение не записывает в SQLite:
его безопасно обрабатывает Firebase Authentication.

Для веб-сборки один раз загрузите SQLite WASM-файлы:

```sh
dart run sqflite_common_ffi_web:setup
```

## Запуск

```sh
flutter pub get
flutter run
```

Демо-карточки показывают основные состояния интерфейса при первом запуске.
